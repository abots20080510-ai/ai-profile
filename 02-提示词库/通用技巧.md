# 提示词库 · 通用技巧

> 跨场景通用的提示词工程心得，踩坑换来的。

## 1. 五条铁律

1. **先给上下文再给任务**——AI 不知道你是谁、材料从哪来，先铺背景再派活
2. **输出格式写死**——"用表格输出""分三段""每段不超过 50 字"，不写就会自由发挥
3. **要过程不要只要结论**——"列出你的依据"能显著降低瞎编概率
4. **分段长任务**——一次让它做 3000 字规划不如先做大纲、再逐节展开
5. **给反例**——"不要 XX 腔""不要用 emoji"，负面清单比正面要求更有效

## 2. 让 AI 不瞎编的三件套

```
1. 回答前先声明：哪些是你查证过的事实，哪些是推断（推断标置信度）
2. 引用数据必须带来源和日期，查不到就明说"未查证"
3. 不确定时说"不确定"，禁止用流畅的语言掩盖不确定性
```

## 3. 长对话防跑偏

- 定期让 AI 复述当前任务目标和约束（"现在回顾一下我们的要求和进度"）
- 关键决策让 AI 输出成文字存档，防上下文压缩丢失
- 多轮修改后质量下降时，开新对话重贴材料比继续纠缠更省时间

## 4. 方案确认流程（合作类任务）

```
1. AI 先出 2-3 个候选方案，每个讲清利弊，用大白话
2. 用户圈选一个或组合
3. 确认后再动手执行
禁止：跳过确认直接交付，或者用术语让用户"不知所然地跳过"
```
