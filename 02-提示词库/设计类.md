# 提示词库 · 设计类

> 面向 ComfyUI / Stable Diffusion 1.5 的提示词与工作流约束模板。

## 1. SD1.5 提示词骨架

```
正面：masterpiece, best quality, 【主体描述】, 【风格词】, 【构图词】, 【光照词】, detailed
负面：lowres, bad anatomy, bad hands, extra digits, watermark, signature, jpeg artifacts, worst quality, blurry
```

**经验值**：
- SD1.5 建议 512×768（竖版）或 768×512（横版），超过 800 长边容易肢体崩坏
- 风格词宁少勿多，3 个以内最稳；想锁风格优先训练/使用 LoRA 而不是堆提示词
- 采样：DPM++ 2M Karras，步数 20-28，CFG 6-7 是万金油起点

## 2. 钢笔速写风格（电商封面用）

```
正面：monochrome, ink sketch, pen and ink drawing, cross-hatching, 【主体】, white background, clean lines
负面：color, watercolor, oil painting, gradient, photo, realistic, 3d render
```

**要点**：负面提示词里明确排除 watercolor 是关键——否则经常跑偏成水彩。此风格用于电商封面时统一加 white background 方便后期抠图。

## 3. ComfyUI 工作流搭建约束（写给 AI 的）

```
硬件环境：P104-100 8G 矿卡（Pascal 架构，sm_61）
约束：
1. Torch 版本 ≤ 2.7.1（Pascal 最后支持）
2. CUDA 用 cu124/cu126 索引，不要用新版本
3. 显存 8G，出图分辨率控制在 512 基础倍率内，避免 OOM
4. 节点方案优先 SD1.5 生态，SDXL 及以上不考虑
```

## 4. 电商产品图工作流

1. 产品实拍图 → 抠图（白底统一）
2. SD 生成场景底图（提示词骨架 + 场景词）
3. 产品合成回场景（手动 PS 或 inpaint）
4. 统一加品牌元素
- **关键**：产品主体永远用实拍，AI 只做场景和氛围——直接 AI 生成产品会出现形变导致售后纠纷
