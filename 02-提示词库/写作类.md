# 提示词库 · 写作类

> 收录日常使用中反复打磨过的写作类提示词模板。使用时把【】内替换成实际内容。

## 目录

- 1. 长篇连载续写
- 2. 公众号文章
- 3. 电商文案
- 4. 歌词打磨

---

## 1. 长篇连载续写

```
你是一位长篇小说连载作家。请续写以下内容。

【世界观与人物设定】
（粘贴设定文档）

【前文最后三段】
（粘贴）

要求：
1. 保持既定主线和伏笔，不得引入与设定冲突的新设定
2. 对话占比不低于 40%，节奏欢快、少悲情
3. 结尾留下一个小钩子
4. 字数：1200-1500 字
```

**要点**：先给设定再给前文，比只说"继续写"质量高一个档次；伏笔清单单独维护。

## 2. 公众号文章

```
为公众号【账号名】写一篇关于【主题】的文章。

受众：【目标读者】
基调：整体欢快、有趣、耐回味，少悲情
硬性要求：
1. 主线和包袱保持既定设计，不得自行发挥主线
2. 标题避开 AI 模板腔（禁用"揭秘""震撼""一文读懂"）
3. 篇末必须带互动问题（多选形式）+ 话题标签
4. 字数：1500-2500 字
```

---

## 3. 电商文案

```
为产品【名称】写电商详情页文案。

卖点（按优先级）：1.【】 2.【】 3.【】
目标客群：【】
要求：场景化开头，卖点用"利益点+证据"格式，禁用绝对化用语，150 字内主文案 + 3 条短标题。
```

## 4. 歌词打磨

```
这是歌词初稿：【粘贴】

请做打磨而非重写：
1. 保留原句中不押韵但有味道的表达（这是特征不是缺陷）
2. 只调整生硬、口语义处，改动处标注理由
3. 保持段落结构对应预设曲式（A/B 段）
4. 输出修改对照表：原句 / 改句 / 理由
```

**要点**：AI 重写歌词会丢"人味"，必须限定"打磨"而非"重写"。
