# 电商设计 · 项目档案

## 定位

AI 辅助原创设计与电商视觉素材生产，服务自身产品线与海外平台分发。

## 工具环境

- ComfyUI + Stable Diffusion 1.5（P104-100 8G 矿卡本地部署）
- Torch ≤ 2.7.1 + cu124/cu126（Pascal 架构末端支持组合）

## 分发渠道

Etsy / Civitai / Pinterest 三平台，各平台素材规格与运营策略不同（见工作流文档）。

## 内容原则

- 原创 IP 形象优先，不做真人换脸类内容
- 产品主体一律实拍，AI 只做场景与氛围
- 风格资产化：有效果的风格固化为 LoRA 与提示词模板（见提示词库"设计类"）
