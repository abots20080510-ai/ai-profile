# 工作流 · AI 绘图（ComfyUI + SD1.5）

## 硬件环境

| 组件 | 规格 |
|---|---|
| GPU | P104-100 8G 矿卡（Pascal 架构） |
| PyTorch | ≤ 2.7.1（Pascal sm_61 末端支持版本） |
| CUDA | cu124 / cu126 索引 |

## 标准出图流程

```
构思（题材/构图/风格）
  → 加载 SD1.5 底模 + 风格 LoRA
  → 提示词骨架（见 02-提示词库/设计类.md）
  → 512 基础分辨率出图（20-28 步）
  → 不满意 → 调提示词重跑（不调步数）
  → 满意 → 高清修复放大（hires fix, 1.5x）
  → 后期抠图/合成
```

## 平台分发

- Etsy / Civitai / Pinterest 三平台同步
- Civitai：发布模型和 LoRA 时附示例图与触发词说明
- Pinterest：竖版 2:3 优先，标题带关键词
- Etsy：产品图统一白底，场景图做氛围展示

## 稳定性经验

1. 出图前先跑一张 512 低步数测试构图，省时间
2. 显存爆了先降分辨率，再减 LoRA 数量
3. 环境别乱升级——Torch/CUDA 版本锁死在验证过的组合上
4. 批量任务放夜间跑
