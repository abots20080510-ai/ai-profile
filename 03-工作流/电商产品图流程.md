# 工作流 · 电商产品图（农业 SKU）

## 应用场景

胚芽米高端 SKU（康养定位）的产品详情页与推广素材。

## 流程

```
1. 产品实拍（自然光，白米/米袋/田间场景）
2. 抠图统一白底
3. AI 生成场景底图（木质餐桌/厨房/田园氛围）
4. 实拍产品合成进场景
5. 文案叠加（卖点：留胚率/产地/工艺）
6. 多尺寸导出（详情页 750px 宽 / 主图 800×800）
```

## 内容红线

1. **产品主体永远用实拍图**——AI 生成米粒/包装会出现形变，引发货不对板纠纷
2. 功效描述只写可验证项（留胚率、出米率有实测数据支撑），不碰医疗保健类宣称
3. 场景图 AI 生成的餐具/装饰避免明显品牌 logo

## 配套数据

- 每批次加工数据（留胚率、出米率、碎米率）作为文案证据存档
- 定价与规格变动时同步更新全部素材，避免新旧价格并存
